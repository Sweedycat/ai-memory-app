# AI Memory App

AI Memory is a privacy-first mobile memory assistant designed to help people remember who they met, what they discussed, and what to follow up on.

## MVP goals

- Save people and lightweight profile notes
- Record interactions and meeting notes
- Surface a quick "What do I know about this person?" summary
- Create follow-up reminders
- Keep the phone app as the core product
- Leave a clean integration path for smart glasses later

## Initial stack

- React Native
- Expo
- TypeScript
- Local mock data first
- Supabase planned for authentication, database and sync

## Product principle

The app should work well on a phone by itself. Smart glasses are an optional extension, not a dependency.
